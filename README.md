# 🎮 Nexus Gaming

**Portal de jogos e notícias gamer** desenvolvido como projeto acadêmico da disciplina **Desenvolvimento Front-End Para Web**, da **Universidade Positivo**.

O Nexus Gaming reúne conteúdos demonstrativos sobre jogos em uma interface escura, com navegação entre dez páginas e recursos interativos desenvolvidos para praticar HTML, CSS, JavaScript e Bootstrap.

> **Aviso:** as notícias, os jogos apresentados e as datas do portal são conteúdos fictícios/demonstrativos, utilizados para fins acadêmicos.

## 🚀 Funcionalidades

- Navegação entre **10 páginas** com identidade visual consistente;
- Layout responsivo para computador e celular;
- Notícias com recursos de filtragem;
- Análises e lançamentos de jogos;
- Galeria de imagens;
- Reprodução de vídeo e áudio com controles nativos;
- Quiz gamer interativo com pontuação;
- Lista de jogos favoritos;
- Formulário de contato com validações HTML;
- Persistência local de dados com `localStorage`.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura e elementos semânticos;
- **CSS3:** estilização, Grid, Flexbox e responsividade;
- **JavaScript:** eventos, manipulação do DOM e armazenamento local;
- **Bootstrap:** componentes e classes utilitárias nas páginas que utilizam a biblioteca.

Os arquivos necessários do Bootstrap estão incluídos localmente no projeto. As páginas de Galeria e Quiz utilizam HTML, CSS e JavaScript sem Bootstrap.

## 💻 Como executar

1. Baixe o repositório em **Code → Download ZIP** ou clone o projeto.
2. Extraia o arquivo ZIP, se necessário.
3. Abra a pasta do projeto.
4. Dê dois cliques em **`index.html`** para abrir o site no navegador.
5. Use o menu para acessar as demais páginas.

**Não é necessário instalar dependências, iniciar servidor ou estar conectado à internet para executar os recursos locais do projeto.**

## 🔒 Armazenamento de dados

As informações de favoritos, pontuação do quiz e contato são armazenadas **localmente no navegador**, por meio de `localStorage`. O formulário não envia mensagens para um servidor. Os dados podem ser removidos ao limpar o armazenamento do navegador.
