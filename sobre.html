Sobre o Nexus Gaming

O Nexus Gaming é um projeto acadêmico de Front-End criado para demonstrar navegação, design responsivo e interatividade com HTML5, CSS3, JavaScript e Bootstrap.

Missão

Oferecer uma experiência de navegação simples e agradável para quem gosta de jogos, reunindo conteúdo demonstrativo em uma interface acessível.

Equipe

Tecnologias

HTML semântico, CSS Grid, Flexbox, JavaScript puro, Bootstrap local e localStorage.

Os títulos, notícias, notas e datas de jogos são fictícios.
